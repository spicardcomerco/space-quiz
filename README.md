# Orbit Quiz

A self-contained space exploration quiz with 10 questions, live score and progress, animated answer feedback, and a results screen.

## Run

Open `index.html` directly in a modern browser. No server, build step, or dependencies are required.

## Features

- Responsive, narrow-column layout with a space-inspired hex background.
- Light and dark themes that follow the system color scheme.
- Progress indicator, score counter, and animated correct/incorrect answer states.
- Keyboard-accessible answer buttons, live feedback, and reduced-motion support.
- Final score with an emoji reaction and a replay option.

## Project structure

- `index.html` contains the markup, styles, quiz data, and application logic.
- `.github/copilot-instructions.md` provides repository-specific guidance for future Copilot sessions.

## Manual smoke test

Start the quiz, answer a question correctly and another incorrectly, and continue through all 10 questions. Confirm feedback, score and progress updates, the final results screen, and replay behavior.
